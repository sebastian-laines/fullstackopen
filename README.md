# Full Stack Open

Repositorio personal para los ejercicios y proyectos del curso **Full Stack Open** de la Universidad de Helsinki.

Curso: https://fullstackopen.com/es/

## Organización del repositorio

Los ejercicios se organizarán por parte del curso:

```text
fullstackopen/
├── part0/
├── part1/
├── part2/
├── ...
└── part13/
```

Las carpetas se irán creando conforme avance en el curso para evitar archivos vacíos o innecesarios.

## Flujo de trabajo

1. Trabajar cada ejercicio en la carpeta correspondiente.
2. Revisar los cambios con `git status`.
3. Crear commits descriptivos.
4. Subir los cambios a GitHub con `git push`.
5. Registrar los ejercicios en el sistema de entregas de Full Stack Open solamente cuando la parte esté lista para enviarse.
